# AI内容过检

不是教你骗平台，是帮你找到内容里真正让算法觉得"这是机器写的"的地方，把它补上。

2026年小红书严打AI批量内容，平台每天新增300万篇笔记里60%是AI生成的。平台不看你用没用AI写，它看的是内容是否有真实体验感。

这个 Skill 帮你扫描内容里缺少"真实性信号"的位置，挖出你真实的细节，让内容更像一个真实的人有真实经历之后写出来的东西。

## 这个 Skill 适合谁

- 担心内容被平台判断为AI生成的创作者
- 用AI辅助写作但不想被限流降权的博主
- 内容明明有干货，但总感觉读起来"不像真人写的"
- 发出去数据特别差，怀疑是AI检测问题

## 它能做什么

- 扫描五类真实性信号缺失（具体性/情绪痕迹/时间锚点/个人视角/不完美描述）
- 识别五类高风险内容模式（结构完美/全程正面/句式雷同/无个人指代/大词堆叠）
- 问你几个问题挖出真实细节，帮你融入内容
- 改写并对比原文，标出改了什么、为什么改
- 不推荐任何绕检测的技术手段，只帮你提升内容真实性

## 典型使用场景

- "这篇会不会被判AI？"
- "内容被限流了，是不是AI检测问题"
- "帮我看看哪里太像机器写的了"
- "怎么降AI率"
- "发了数据特别差，内容没问题但没有流量"

## 推荐输入格式

直接粘贴内容，或者说明：
1. 内容文本（标题 + 正文）
2. 这篇内容是怎么写出来的（自己写/AI辅助/AI生成后修改）

## 输出长什么样

默认输出：

1. 真实性信号扫描结果（五类，各判断有/缺失）
2. 高风险模式识别（命中哪几类）
3. 最需要补的一处（只给优先级最高的）
4. 帮你挖真实细节的 2-3 个问题
5. 融入细节后的改写对比
